# 🐾 Proyecto Final Programación Backend III

El aplicativo sobre el que se desarrolló el proyecto final de backend es diseñado para facilitar el proceso de adopción de mascotas. En su versión inicial, permite gestionar usuarios, mascotas y solicitudes de adopción de manera sencilla y eficiente.

## 🐳 Imagen en Docker Hub

Podes acceder a la imagen del proyecto en Docker Hub a través del siguiente enlace:

👉 [Ver imagen en Docker Hub](https://hub.docker.com/r/agustinbegue/final-backend3)

## 🚀 Funcionalidades principales

### 👤 Sistema de Usuarios
- Obtener todos los usuarios registrados.
- Consultar un usuario específico por su ID.
- Registrar nuevos usuarios.
- Actualizar datos de un usuario existente.
- Eliminar usuarios del sistema.

### 🐶 Sistema de Mascotas
- Listar todas las mascotas disponibles.
- Registrar una nueva mascota.
- Editar información de una mascota.
- Eliminar mascotas del sistema.

### 📝 Sistema de Adopciones
- Ver todas las solicitudes de adopción.
- Consultar una solicitud por su ID.
- Crear una nueva solicitud de adopción entre un usuario y una mascota.

## 💡 Descripciones breves del sistema

- **Gestión integral:** El sistema permite administrar usuarios y mascotas mediante operaciones CRUD, garantizando el control total del proceso.
- **Proceso de adopción sencillo:** Vincula usuarios y mascotas para registrar adopciones de forma rápida y segura.

## 📌 Objetivos del Proyecto Final

- ✅ Se documentó con **Swagger** todo el módulo de `Users`.
- ✅ Se desarrollaron **tests funcionales** para todos los endpoints del router `adoption.router.js`.
